# Kia Static Web

A static Kia website clone — plain HTML & CSS, no build tools.

## Run Locally

Just open `index.html` in your browser. No install needed.

Or serve it locally:
```bash
git clone https://github.com/Jahanad-pr/KIa-static-Web_.git
cd KIa-static-Web_
npx serve .
```

## Deploy

Drag-and-drop the folder into **Netlify** (netlify.com/drop), or use **GitHub Pages**:
1. Repo settings → Pages
2. Source: `main` branch, root folder
3. Save
